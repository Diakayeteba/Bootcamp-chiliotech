   -----------------------------------------------------
   Ce fichier me sert à pratiquer les notions suivantes :

   2. Mise en page

   -----------------------------------------------------
   RAPPEL IMPORTANT

   margin  = espace extérieur
   padding = espace intérieur

   Exemple :

   +-----------------------+
   |      margin           |
   |  +---------------+    |
   |  |   padding     |    |
   |  | +-----------+ |    |
   |  | | contenu   | |    |
   |  | +-----------+ |    |
   |  +---------------+    |
   +-----------------------+

   ===================================================== */


/* =====================================================
   STYLE GLOBAL DE LA PAGE
   ===================================================== */

/*
html, body :
- S'applique à toute la page.
- Définit la police, la taille du texte
  et supprime les marges par défaut du navigateur.
*/
html,
body {
    position: relative;
    font-size: 16px;
    font-family: 'Open Sans';
    padding: 0;
    margin: 0;
}

/*
Couleur de fond générale de la page.
*/
body {
    background-color: hsl(345, 28%, 83%);
}


/* =====================================================
   TITRES ET TEXTES
   ===================================================== */

/*
Classe utilisée pour les grands titres.
*/
.titre {
    font-size: 24px;
}

/*
ID utilisé pour une description secondaire.
*/
#description {
    font-size: small;
}


/* =====================================================
   BOUTONS
   ===================================================== */

/*
Style de base d'un bouton.

background      = couleur de fond
border          = supprime la bordure
cursor:pointer  = affiche la main au survol
border-radius   = arrondit les angles
box-shadow      = ajoute une ombre
*/
.button {
    background: #f55151;
    border: none;
    cursor: pointer;
    border-radius: 10px;
    font-weight: 100;
    box-shadow: 1px 1px 1px rgb(248, 1, 1);
}

/*
Effet au passage de la souris.
*/
.button:hover {
    background: rgb(8, 64, 217);
    color: white;

    /*
    transition :
    permet d'animer les changements.
    */
    transition:
        background-color 0.01s,
        color 0.01s,
        all 1s;
}


/* =====================================================
   LIENS
   ===================================================== */

/*
:hover = état lorsque la souris passe dessus.
*/
.link:hover {
    color: #630eeb;
    text-decoration: none;
}


/* =====================================================
   HEADER / NAVIGATION
   ===================================================== */

/*
display:flex

Permet d'aligner les éléments
horizontalement ou verticalement.

C'est l'une des propriétés les plus
utilisées en CSS moderne.
*/
header {
    display: flex;

    /*
    Espace automatiquement les éléments.
    */
    justify-content: space-between;

    /*
    Centre verticalement.
    */
    align-items: center;

    height: 30px;
}

/*
Logo du site.
*/

    flex: 1;

    text-decoration: none;
    padding: 0 15px;
}

/*
Barre de navigation.
*/

    display: flex;
    text-align: right;
}

/*
Liste des menus.
*/
.nav ul {
    list-style: none;
    display: flex;
    margin: 0;
    flex: 1;
}

/*
Liens du menu.
*/
.nav > ul li > a {

    padding: 3px;
}


/* =====================================================
   FOOTER
   ===================================================== */

/*

*/

    padding: 10px 0;
}
